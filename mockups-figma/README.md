# ALONG — HTML/CSS-макеты для Figma

Статические экраны приложения без JavaScript и без Flask. Нужны, чтобы
перенести интерфейс в Figma, собрать презентацию или показать макет
заказчику.

## Что внутри

| Файл | Экран |
|---|---|
| `preview.html` | Галерея всех макетов |
| `index.html` | Главная |
| `trips.html` | Поиск поездок |
| `trip.html` | Карточка поездки |
| `trip-new.html` | Публикация поездки |
| `schedule.html` | Расписание транспорта |
| `route.html` | Построение маршрута |
| `login.html` | Вход |
| `register.html` | Регистрация |
| `profile.html` | Личный кабинет |
| `support.html` | Поддержка |
| `admin.html` | Админка: обзор |
| `admin-trips.html` | Админка: поездки |

Ширина макетов рассчитана на **1440 px**. Все страницы связаны ссылками,
поэтому по ним можно ходить как по обычному сайту.

## Как посмотреть

Откройте `preview.html` двойным щелчком. Если браузер ограничивает
локальные файлы, запустите статический сервер из этой папки:

```powershell
python -m http.server 8090
```

Затем откройте `http://127.0.0.1:8090/preview.html`.

## Как импортировать в Figma

1. Установите плагин **html.to.design** (или аналогичный HTML → Figma).
2. Запустите локальный сервер из папки `mockups-figma` (см. выше).
3. В плагине выберите **Import from URL** и укажите адрес нужного экрана,
   например `http://127.0.0.1:8090/index.html`.
4. Ширину фрейма задайте **1440 px**, высоту — по содержимому.
5. Повторите для остальных экранов.

Если плагин просит файл, укажите HTML-файл напрямую. Стили подключены
относительной ссылкой `styles.css`, картинки лежат в `assets/`.

Для точного совпадения шрифтов установите в Figma **Inter** (Google Fonts).
Без него Figma подставит системный шрифт.

## Особенности статических макетов

- Нет JavaScript: календарь показан кнопкой с выбранной датой, карта —
  снимком, видео на главной — кадром из ролика.
- Формы не отправляются: это макеты, а не рабочее приложение.
- Адаптивность сохранена, но мобильные фреймы в набор пока не входят.
- Ассеты: `assets/images/` — фотографии, `assets/map-trip.png` и
  `assets/map-route.png` — снимки карт, `assets/hero-still.jpg` — кадр видео.

## Как пересобрать

Макеты сгенерированы из рабочего приложения скриптом
`scripts/build_figma_mockups.py`. Ему нужен запущенный сервер и известные
пароли демо-аккаунтов:

```powershell
python scripts/build_figma_mockups.py `
  --base-url http://127.0.0.1:5055 `
  --admin-password "<пароль админа>" `
  --user-password "<пароль пользователя>"
```

Скрипт скачивает страницы, убирает скрипты и CSRF-токены, переписывает
ссылки на локальные файлы и подставляет заглушки вместо карт и видео.
